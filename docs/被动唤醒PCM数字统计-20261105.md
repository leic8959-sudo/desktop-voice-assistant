## 统计语义

生产仅改 gateway.py。保留原 `_note_wake_input` 的消息计数，新增 `_note_wake_pcm` 在发送前统计接收 PCM：使用 `<h` 按小端有符号 PCM16 逐样本解析，最先收到的 64000 个样本归 head，其后归 tail。在 16kHz 单声道约定下 head 对应上传顺序首 4 秒，**不等于固件实际冻结的唤醒前缀**；没有新的固件边界标记，不能以 head/tail 还原前缀、后缀或具体词段，也不能仅凭数字证明采样率正确。

内存固定为两桶，各保存 samples、sum_squares、peak、zero_samples、clipped_samples 五个整数累加器；每帧只遍历一次，工作量随本帧样本数增长，不随历史数据重扫。没有增长的帧队列或 PCM 缓存。clipped 使用现有诊断习惯 abs(sample)>=32767，包含 32767 和 -32768；peak 可为 32768。空桶 RMS 为 0，其余以 `math.isqrt(sum_squares // samples)` 输出整数 RMS。

只向原来唯一的 wake_gate_summary 增加 10 个固定整数，不新增摘要条数：

| 字段 | 含义 |
| --- | --- |
| pcm_head_samples / pcm_tail_samples | 桶内样本数 |
| pcm_head_rms / pcm_tail_rms | 整数 RMS |
| pcm_head_peak / pcm_tail_peak | 最大绝对幅度 |
| pcm_head_zero_samples / pcm_tail_zero_samples | 精确为零的样本数 |
| pcm_head_clipped_samples / pcm_tail_clipped_samples | 绝对幅度至少 32767 的样本数 |

只有需要唤醒复核、尚未通过且摘要尚未输出时扫描。manual、accepted 或 summary_sent 后直接返回，不扫描或更新桶。原成功 append 计数仍在实际 await send 返回后增加；发送失败只留下已收到的数据统计，不冒称 ASR 确认或发送成功。数字可帮助区分近静音、全零或削波，但不能识别说了什么、证明完整口令、定位设备丢帧或替代真人验收。
