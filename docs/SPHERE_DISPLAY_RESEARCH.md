## 1. 成像原理

这是经典的**分光镜反射成像**(Pepper's Ghost 变体):

```text
        ┌─ 亚克力半球罩(内表面上半部镀/贴分光膜)
        │   ↑ 观众从侧面看到画面"贴"在球面内
   ┌────┴────┐
   │ 分光膜面 │  ← 40%~50% 反射,其余透射
   └────┬────┘
   │ 屏幕(朝上)│  ← 黑底高亮内容
   │  设备仓   │  ← 主控/喇叭/麦克风/电池
   └─────────┘
```

屏幕发出的光在膜面反射形成虚像,因膜是球面的一部分,画面观感"贴"在球壳上;膜同时透光,环境亮处膜面像镜子,内部暗处透出设备轮廓。

## 2. 三条工艺路线

| 路线 | 做法 | 优点 | 缺点 | 成本 |
|---|---|---|---|---|
| A. 卷膜贴内表面 | 单向透视膜/分光膜静电贴到半球内表面 | 最便宜最快,可当天验证 | 曲面贴膜易皱;膜与亚克力两个面各反射一次,重影明显 | ¥10~30(膜)+¥15~40(半球) |
| B. 定制镀膜 dome | 工厂真空镀半透介质膜在半球内表面(可加 AR 减反) | 观感最好,重影可控,分光比可选 | 要开模/定制,打样周期与费用高 | 样品估 ¥100~300/件,量大降 |
| C. 现成安防 two-way dome | 买单向可见安防半球反着用 | 现成镀膜 | 桌面尺寸(80~120mm)难找,安防规格多为 300mm+ | $20~100 |

**建议:A 验证观感 → B 定制量产观感。** C 仅供了解,不推荐。

光学参数依据(来源见文末):
- 50:50 分光立即损失约 50% 亮度;可选 40R/60T 等比例(teleprompter 常用 40R/60T,2mm 玻璃 4"×4" 约 $9.95);
- 重影来自膜前后两面反射,薄基材+紧贴可减轻,介质镀膜/AR 背镀可基本消除;pellicle(微米级膜片)可完全消除但脆弱昂贵;
- 3mm 厚亚克力是半球常见规格,基材越薄重影错位越小,但结构强度下降。

## 3. 结合现有硬件的可行性

| 项 | 结论 |
|---|---|
| 屏幕复用 | 现有 ESP32-S3-Touch-AMOLED-1.8-v2(368×448,显示区约 34×42mm)**可作为光学验证的图像源平放使用**;正式形态建议升级 2.4"~3.4" 圆形/方形屏,画面占球面比例更饱满 |
| 亮度 | AMOLED 全白约 500nit,经 40%~50% 反射后约 200nit,室内桌面可看清;**黑底高亮内容是硬要求**(黑底让膜面"消失") |
| 内容 | 现有 web 测试台 canvas 表情(368×448)逻辑可直接复用;主题需改为纯黑背景+居中主体+字幕下沉,避免大面积亮色 |
| 语音链路 | 不受影响,仍走小智固件 + 本地桥接;结构改造是显示层与外壳的事 |
| 风险 | 环境光强时膜面照镜子,画面被冲淡;最佳观看角约正侧方 ±45°,顶部/底部视角差 |

验证步骤:
1. **平面镜快速判定**(成本最低):平板玻璃或亚克力板贴膜 → 手机放下方播黑底动画 → 看重影间距和亮度,确认分光比观感;
2. 半球贴膜(只贴上半球内表面,膜面朝内)→ 1.8" 板朝上放球心下方 → 播放黑底表情 → 侧视看"贴球面"效果;
3. 记录:重影错位量、环境灯开/关两种条件下的画面可读性、各角度观感;
4. 观感达标后,再设计设备仓(3D 打印、喇叭/麦克风开孔、电池仓)并向工厂询价镀膜 dome(搜索词:"半球 真空镀膜 分光膜 半透 定制 1688")。

## 5. 与产品路线的关系

- 本结构解决"玩具感"的**观感层**;上一轮结论仍然成立:能力层(家居控制、记忆、任务)在桥接服务里做,不依赖外壳;
- 建议顺序:先完成方案文档第 9.4 节的功能扩展链路(家居单设备),再做外壳——外壳改型不影响桥接与固件逻辑;
- 风险提示:圆屏/大屏换型后,固件板型配置需重新适配(屏幕驱动、LVGL 分辨率),属于 P09 范畴的延伸,不要在光学验证前投入。
