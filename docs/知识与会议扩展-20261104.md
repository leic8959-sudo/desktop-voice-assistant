# 知识、会议与语言扩展（2026-11-04）

## 接入合同

服务位于 `src/assistant_app/application/knowledge.py`，构造为 `KnowledgeService(config, store, runtime, http)`；生命周期为 `await start()` / `await close()`。`tool_schemas` 为现有项目使用的 function JSON schema 列表，统一语音入口为 `await invoke(name, args, subject="voice")`。当前沿用单用户模型，网页和语音均使用 `owner` 空间；这不是多人身份隔离。

`complete_text(config, http, messages, *, max_tokens=800, json_mode=False) -> str` 可供父模块记忆抽取复用。根据当前 `llm_provider` 选择 DeepSeek，其他模式使用已配置的千问文本模型，沿用 `chat_pipeline` 的兼容端点和 thinking 参数；连接10秒、读取90秒、总计120秒。响应限定512 KiB；HTTP错误、无效JSON、空内容、输出被截断和超时均作为真实失败返回，不保存API Key、不静默切换供应商、不展示上游原始响应中的敏感内容。

路由位于 `src/assistant_app/api/knowledge.py`，导出 typed `KNOWLEDGE_KEY` 与 `register_routes(app)`。父模块需在现有 gateway 生命周期创建服务、放入 `app[KNOWLEDGE_KEY]`、调用 start/close 并注册路由。API全部在现有 `/api/` 认证、同源校验和审计边界下，不增加认证旁路。当前页面为 `/static/knowledge.html`，令牌仅取本页密码框，本机登录复用 Cookie；JSON与multipart均复用 `console_api.js`。

| 路由 | 行为 |
| --- | --- |
| GET `/api/knowledge/status` | 当前容量、模型标识和凭据配置状态（不证明连通性） |
| GET `/api/knowledge/documents` | `cursor`/`limit` 游标分页 |
| POST `/api/knowledge/import` | multipart `file`，或JSON `filename/content` |
| GET/PUT/DELETE `/api/knowledge/documents/{document_id}` | 查看正文、替换并重建索引、删除正文与索引 |
| GET `/api/knowledge/search?q=...` | 全文检索，返回文件名、片段序号、字符位置和原文 |
| GET `/api/meetings` | 已保存会议的游标分页 |
| GET/DELETE `/api/meetings/{meeting_id}` | 查看或删除转写与纪要 |
| POST `/api/meetings/audio` | multipart `authorized=true` 与PCM WAV `file`，仅返回转写 |
| POST `/api/meetings/minutes` | JSON `title/transcript`，生成并保存本地纪要预览 |
| POST `/api/language/translate` | JSON `text/source/target`，中俄英翻译 |
| POST `/api/language/practice` | JSON `text/language/level/answer`，练习或回答纠错 |

## 资料与持久存储

只处理用户主动提供的 UTF-8 `txt/md/markdown/html/htm`，不扫描磁盘、不读取用户传入的路径。文件名拒绝路径分隔符；HTML只提取正文，不执行脚本或加载链接；结果均由浏览器以纯文本展示。PDF、DOCX、图片OCR和扫描件不在现有依赖支持范围，页面明确限制可选格式。

单文件2 MiB、提取正文20万字符；按约1800字符分块，最多200段。全文索引用SQLite FTS5，汉字加入单字/双字索引，拉丁和西里尔词保留词级索引；查询使用索引和最多20条结果，返回原文来源引用。它提供词项检索，不声称向量语义检索或自动验证资料事实。

SQLite保存在现有 `store.path` 所在受控运行目录中的 `knowledge.sqlite3`；不修改旧 AssistantStore 表。资料最多100份、总计500万字符；会议最多50份，转写加纪要总计100万字符。容量用事务内计数更新，不做全表实时聚合。更新/删除在SQLite `BEGIN IMMEDIATE` 事务内同步正文、分块、FTS索引和容量，外键清理分块；网络服务不涉及跨库事务。

所有持久记录180天过期；过期资料不会被读出，启动和资料/会议列表、检索等入口按过期索引分批清理，每次最多50份资料和50份会议。时间存UTC带时区ISO8601。此部署是有界的单用户SQLite本地存储，多实例共享该文件由SQLite事务串行写入；不是面向数百万用户的共享SQLite云服务。

## 录音、转写与纪要

浏览器只有在显式点击“开始录音”后请求麦克风，复用现有 `/static/recorder.js` 的 AudioWorklet 采样，生成单声道16kHz/16位PCM WAV。结束录音会关闭轨道和AudioContext，提供本地预听；最长5分钟且PCM最多9600000字节。离开页面关闭麦克风。录音结束不会自动上传，需另外勾选处理授权、点击“上传音频并转写”。用户也可上传同格式WAV；其他音频格式明确拒绝。

服务端上传流30秒截止、文件约9.2 MiB上限；验证WAV格式、采样率、位深、声道数、数据完整性和0.1秒至5分钟时长。授权缺失时拒绝调用云端。音频只驻留请求内存，不写入服务器文件或数据库。

转写复用 `dashscope_ws_url(config)`、阿里Key/工作空间、`chat_asr_model` 和现有run-task/finish-task协议。每100毫秒发送100毫秒PCM，同时读取句子结束结果；最多一个音频任务，360秒总截止，浏览器400秒超时。界面提示一般需等待录音时长。ASR未配置、未接受任务、任务失败、连接错误、格式错误、空转写或超时均显示真实错误，不以部分结果伪装完成。

转写成功填入可编辑文本框，再由用户单独生成纪要。文本模型将转写作为不可信资料整理，结论、负责人/截止时间未知时明确说明、待办、风险和引用只作为预览，不触发外部文档写入、创建任务或发送消息。会议转写最多40000字符；容量满时保留生成的可复制预览并明确“未保存”，不丢弃模型结果或假称已保存。

## 语言练习

翻译支持 `zh/en/ru`，源语言可自动识别，输入最多12000字符；练习支持A1–C2，主题/题目最多6000字符、回答最多6000字符。实际调用当前配置的文本模型，返回供应商和模型标识。提供回答时生成纠错、自然表达和下一题；未提供回答则生成练习和参考答案。模型材料只当作资料，不执行其中的工具指令。两个模型任务为并发上限，超过时明确要求稍后重试。
