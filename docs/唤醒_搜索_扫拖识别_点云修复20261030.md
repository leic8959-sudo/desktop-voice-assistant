# 唤醒、搜索、扫拖识别与点云修复

本轮由三个 gpt-6-luna 子代理并行实施，主代理整合并独立静态审查。牛牛确认：待机安静时也经常无法唤醒。

## 已修改的代码

- `home_control.py`：设备查询归一化，增加扫地、扫拖、扫托、机器人等品类同义词。保留房间、型号限定；多台结果交由语音追问。设备能力和授权仍由原有发现与执行路径决定。
- `gateway.py`、`web_search.py`：增加独立 `search_web` 工具。主语音会话保留家居、提醒、Gmail 等工具；独立搜索会话只输出文字，启用内置搜索，不注册工具。只有服务端返回正数 `usage.plugins.search.count` 才确认实际执行检索。
- `config.example.json`、`config.local.json`：`enable_search` 改为 `true`，含义为启用独立搜索工具。本地配置其余字段与备份比较一致，未修改凭据。
- `firmware/assistant_espidf/main/display_ui.cpp`：屏幕亮度 55% 改为 75%，粒子调色板最低强度约 6% 改为 18%，补点阈值 20 改为 16。保留粒子数、PSRAM、DMA、QSPI 与显示调度。
- `firmware/assistant_espidf/main/wake_word.cpp`：优先选择历史验证过的 `mn5q8_cn`，增加输入 RMS、峰值和缓冲丢弃计数。已撤掉没有效果的 4 倍数字增益，按小智 `CustomWakeWord` 用原始 AFE 输出喂 MultiNet。
- `firmware/assistant_espidf/main/audio_io.cpp`：按小智同板实码对齐 ES8311 输入增益 30dB、AXP2101 ALDO1 3.3V 读写校验、10ms原始采音；无播放参考时旁路软件 AEC，播放与尾音阶段保留 AEC。

唤醒修改仍未解决本次待机漏唤醒：对齐版离线观测中，牛牛现场说 5 次只记录到 1 次，不能称为通过。日志显示 `microphone_power aldo1_mv=3300`、`microphone_gain_db=30`、`capture_frontend software_aec=0`，且 `pending_resets=0`；因此已排除“缓冲丢帧”和“只把数字增益调低”这两条解释，但尚不能证明硬件模拟链路或声学条件完全正常。

## 当前运行环境的只读证据

在修改后重启或烧录前，通过现有 8765 桥接接口进行只读查询：

- `/api/status`：设备已连接，状态 `idle`。
- `/api/home?enabled_only=true&limit=30`：米家扫拖机器人 M40 已接入且已授权，目录 `stale=false`，无发现错误。
- 旧运行进程查询“扫拖机器人”能找到 M40，“扫地机器人”和“扫托机器人”结果为空。由此确认名称匹配缺陷。
- M40 当前返回清扫与回充动作，没有返回暂停能力；不能承诺独立拖地、暂停或其他私有能力。只读查询未触发实物动作。

实际执行的是 PowerShell `Invoke-RestMethod` GET，请求令牌只从本地配置读取，未打印。以上结果证明旧进程的复现条件，**不代表新代码已加载或已通过回归**。

联网能力核查使用 PowerShell `Invoke-WebRequest` 读取[阿里云官方 Realtime 文档](https://help.aliyun.com/zh/model-studio/realtime#realtime-tools)。官方明确“联网搜索和工具调用不兼容，不可同时开启”，并给出 `usage.plugins.search.count` 计量结构。因此没有在主工具会话直接开启内置搜索。未调用付费云端模型。

## 下一步验收

还未完成的是可接受的真人唤醒率验收，以及在保持小燕子词不变的前提下整体升级 IDF/ESP-SR 的风险评估。当前设备运行的是本轮对齐版。

建议验收范围：

1. 家居：三种“扫地/扫拖/扫托机器人”查询同一 M40；房间与型号不匹配时不得误选；多台时追问；未授权设备不可控制。
2. 搜索：主会话可调用家居工具，搜索使用独立会话；真实搜索返回计量；没有计量、超时或失败时不编造最新结果。
3. 点云：白天室内环境可视性；连续对话下显示、音频与供电稳定性。
4. 唤醒：安静待机，在固定距离以正常音量说完整“你好，小燕子”，逐次记录命中/漏识别；结合 `wake_input_stats`、候选置信度与缓冲计数定位，不用播放期间的 RMS 替代待机说词证据。

本轮完成的是代码修复、版本对照和现场诊断；联网搜索尚未调用真实云端，扫地机器人尚未发送真实动作，点云亮度尚未得到牛牛主观确认，唤醒命中率仍未验收通过。
