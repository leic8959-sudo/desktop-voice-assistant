# 小燕子音频对齐与AEC实机记录

日期：2026-10-29。牛牛要求Luna并行实现、root整合验收。当前版本以本页后续实机结果和`evidence/aec-alignment-result-20261029.json`为准。

## 已落实

- ESP32-S3运行240MHz，使用32KB指令缓存、64字节数据缓存行；大缓冲和音频任务栈放入PSRAM。
- 独立I2S采音任务、24kHz到16kHz的33抽头FIR、ESP-SR AFE/VAD、独立输出消费路径，避免识别阻塞硬件采音。
- 名称为“小燕子”，板端离线口令为“你好，小燕子”。实测本地SDK的MN5Q8中文模型通过正负样本，置信度约0.932；牛牛确认真人可以免按键唤醒并对话。MN7在本地SDK版本中虽解出拼音但不触发命令，未继续冒用该配置。
- 30秒无有效对话活动返回待机；静音PCM不会延长会话，正常播放计入有效活动。
- 软件参考AEC：将实际播放PCM转换到16kHz作为`esp_aec`参考，AFE接收其处理后的单麦音频。该参考不是硬件回采；可以用于AEC，但质量仍需实际声学测试。
- 新的合法设备连接替换原终端旧连接，避免USB复位后旧连接占位返回503。

## 现场发现及修复

### 语音/屏幕状态互相覆盖

云端倾听/思考消息与本地播放结束争用屏幕。现在播放中暂缓显示倾听、思考和执行，实际播放队列排空后再切换。延迟字幕不会重新将已结束音频标记为正在播放。回归检查中日志显示`deferred=1`，实际音频结束后才切到倾听。

### 点云闪烁、残影与花屏

Waveshare BSP 2.0.3创建的是CO5300 QSPI panel，却调用`lvgl_port_add_disp_rgb`。RGB分支提前`flush_ready`，内部DMA条带可能在QSPI传输结束前被覆盖。已改为`lvgl_port_add_disp`，等待`on_color_trans_done`回调；加入`tools/patch_waveshare_qspi.py`并在构建时校验，以防managed component重建后丢补丁。

点云画布另采用前后台两个PSRAM缓冲，完整绘制后提交。0.1.6烧录后，牛牛确认点云稳定。不能仅从“无SPI错误日志”推断画面正确，因此记录了现场确认。

### 回答约半秒被截断

初版把AEC输出的VAD连续8帧且播放超过500毫秒作为插话条件。残余扬声器回声也能触发VAD，造成助手打断自己；桥接日志中回答开始约0.55秒即回到倾听，与门槛吻合。

0.1.7保留软件AEC，移除仅靠VAD自动取消回答；播放时只在再次识别完整“你好，小燕子”后中断。其余播放期间音频不上传云端，以免残余回声触发云端VAD。该版本不能称为已支持任意自然插话。

## 操作与限制

说“你好，小燕子”进入对话，等回答完整结束后接话；需要中断时再次说完整唤醒词。音色在电脑管理面板保存，下次对话生效。电脑桥接仍需运行，待机音频不持续发送千问。

构建：`tools/build_firmware.ps1`；诊断构建可加`-WakePcmProbe`，正式版本默认关闭，启动不注入测试音频。写入应用及语音模型前已备份0.1.3应用和模型，未擦除NVS。

未修改AGENTS/CLAUDE规则文件，未安装新依赖，未执行Git写入、上传或远程部署。最终回答完整性和点云稳定已获牛牛确认；完整唤醒词中断效果仍需单独复核。
