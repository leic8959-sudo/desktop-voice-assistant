# 设备配对方案与剩余目标

## 已落地

设备无长期 Token 时，首次配网只填写 Wi-Fi 和服务器地址；联网后申请六位配对码并在屏幕引导后台绑定。后台按设备显示的码绑定，设备以 code 和临时 nonce 领取专属凭据、保存 NVS，再连接控制通道。后端支持原子快照、重启恢复、设备凭据认证及撤销。具体接口和领取重试窗口见《设备配对协议》。

官方 ESP-IDF 5.5.6 已安装并完成编译，应用已写入现有设备 app1，未覆盖 NVS、模型和存储。旧设备持有原 Token，恢复连接只能证明兼容启动，不能证明首次配对完成。

## 当前执行目标

- 补齐配对生命周期、重启恢复、保存失败回滚、设备权限及撤销专项验证。
- 完善后台设备读取错误提示与动态字段安全显示。
- 完善独立 HTML 状态演示，区分设计状态与已实装固件状态。
- 完成无 Token 真机显示码、后台绑定、领取保存、断电重连验收；保留现有设备配置，不直接清空 NVS。

## 企业化后续缺口

共享事务存储、多工作区授权、凭据加密与轮换、按管理员身份限制配对失败、设备历史心跳与固件记录尚未完成。动态 HTML 是设计演示，不代表这些能力已实现。不上传仓库。
