# 点云主题 0.1.3

对应牛牛选定的HTML第四方案「无形之形」。已写入ESP32-S3 AMOLED 1.8 V2设备，应用版本0.1.3。仅更新应用分区，Wi-Fi、令牌及唤醒模型分区保留；上一版应用备份在`firmware/backups/native-0.1.2-app.bin`。

## 显示效果

| 状态 | 点云表现 |
|---|---|
| 待机 | 不规则体积缓慢旋转、表面游动 |
| 倾听 | 点云横向展开，青绿色过渡 |
| 思考、执行、连接 | 点云连续卷曲为环状，淡紫色 |
| 回应 | 根据实际PCM播放音量平滑起伏，冷蓝白色 |
| 提醒、提示 | 暖色过渡与缓慢脉动 |
| 异常 | 淡红色点云，保留错误文字 |

中文字体和缺字过滤沿用0.1.2；界面保留主状态、细节文字和侧键操作提示。音色仍在电脑管理面板切换，设备标题中的MORPH表示当前主题；HTML里的音色菜单和放大按钮属于设计预览，本次没有增加设备触摸菜单。

## 实现

768个粒子，368×240绘制区域，RGB565画布；粒子数据、投影、正弦查表和画布合计约202KB PSRAM，另用14720字节内部DMA传输缓冲。固定分配并重复使用，不逐帧创建对象或申请内存。

显示任务固定在核心1，优先级2；只对`display_ui.cpp`启用局部`-O2`优化。定时周期40毫秒是目标调度周期，不代表实际25帧；最终帧率取串口`pointcloud_stats`统计。正常待机实测约17帧/秒，坐标计算约9毫秒/帧；统计不包含LCD传输和LVGL刷新耗时。

首次实机出现显示任务看门狗及PSRAM直接传输失败，最终改为内部DMA条带并调整显示调度。最终检查与初版失败日志分别保存在`evidence/`，不以编译成功替代实机检查。

## 验证与边界

- 构建：`tools/build_firmware.ps1`，官方ESP-IDF 5.5.2，实际编译成功。
- 烧录：`esptool.exe --chip esp32s3 --port COM3 --baud 921600 --before usb-reset --after watchdog-reset --connect-attempts 2 write-flash --no-progress 0x20000 firmware/assistant_espidf/build/assistant_espidf.bin`，写入散列校验成功。
- 实机状态与音频：`python tools/audio_continuity_check.py --ui-cycle`，只使用本地模拟服务器，不调用云端或家居设备；实际结果以`evidence/pointcloud-result-20261029.json`为准。
- 最终结果：状态检查与音频播放期间约15–17帧/秒，32秒串口记录中未出现看门狗、崩溃或屏幕SPI传输错误；300帧/6秒音频缺帧0、溢出0，提醒返回屏幕处理确认。正常桥接已恢复，设备连接且待机，音色仍为Tina。
- 修改范围：显示模块、版本号、该显示文件的编译优化和已有实机检查脚本；音频编解码及网络协议源文件未修改。
- 未新增依赖，未执行Git写入；当前目录不是Git仓库，未上传或发布。

实机粒子数量与帧率已按ESP32性能适配，不能保证与浏览器逐帧相同。屏幕外观与真实云端语音主观听感仍需牛牛现场确认。
