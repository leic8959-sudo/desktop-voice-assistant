# 语音稍后提醒闭环（2026-11-05）

## 行为与范围

此前到期提醒只能从屏幕或网页固定延后 5 分钟，模型没有对应工具。本轮增加跨供应商共用的 `snooze_reminder` 工具，复用既有 `AssistantStore.snooze_reminder` 的事务和记录版本校验，不改数据表、持久化实现或现有 API 合同。

用户可要求 1～60 分钟后再次提醒，未说明时默认 5 分钟。模型先用 `list_tasks` 查询真实 `task_id` 和 `updated_at`，以 `expected_updated_at` 原样传给工具；多个候选先问清目标。只有已到期且未完成的定时提醒能延后；旧版本、已完成、未到期及越界分钟均由原存储层拒绝，冲突后不自动重试写入。

成功后只清除该提醒的旧运行时通知，保留其他通知。语音和 API 的屏幕反馈共用“稍后提醒”操作，显示真实返回的下次提醒时间并明确 UTC，且说明待办仍未完成；不再固定声称“5分钟后”，没有真实时间时显示待核对。网页和屏幕的既有延后动作继续固定 5 分钟。

## 生效与限制

当前只有本地源码变化，未重启网关、联网调用模型或执行真实提醒、设备操作、刷机/OTA、依赖安装、Git 写入。离线通过不代表真实模型能在所有自然语言表达下选对目标或调用工具，仍需单独加载和真人语音验收。
