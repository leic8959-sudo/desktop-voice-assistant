## BOX-3 接线与实现

| 模块 | 本板路径 |
| --- | --- |
| 显示 | 320×240 RGB565/BGR，SPI3 mode0／40MHz；MOSI6／CLK7／CS5／DC4，GPIO48共用LCD／触摸复位，高有效10ms／低后10ms |
| 显示分支 | 面板创建前探测TT21100地址0x24：存在时沿SDK ST7789初始化，否则使用本板ILI9341参数表；探测超时传播，不当作不存在 |
| LVGL／背光 | core1／优先级2，双20行内部DMA共25,600字节；面板及LVGL均明确mirrorXY，无换轴；PWM47低有效逻辑不反转，5kHz/10bit，启动先暗 |
| 触摸分支 | 面板共用复位后，按GT911 0x5D、GT911 0x14、TT21100 0x24顺序探测，IRQ3输入轮询，不另驱动复位或地址选择脚 |
| 触摸坐标 | GT911原始320×240；TT21100镜像X为319-x；多点／错误／越界取消按压并等待合法释放，初始先等释放 |
| 音频 | I²C1 SDA8／SCL18，ES7210双标准槽MIC1/MIC2并选第0槽，ES8311输出；I²S0 mono24kHz，MCLK2／BCLK17／WS45／DOUT15／DIN16 |
| PA | GPIO46先低、解除hold、INPUT_OUTPUT读回；codec PA=NC，checked数字静音确认后才允许PA开启 |
| 输入／网络 | GPIO0按住说话及既有卡片操作；原Wi-Fi配网、六位绑定、HTTP／WebSocket、custom wake“你好，小燕子”、AFE／软件AEC、媒体和双OTA |
| SD底座 | SDMMC四位CLK11／CMD14／D0..3=9/13/42/12，电源GPIO43低有效；不格式化缺失／损坏卡，缺卡不阻止语音启动 |

SPI最大一次传输12,800字节；两个20行LVGL条带合计25,600字节，不是整帧缓存。来源BSP默认单缓冲，本地选择现有双条带路径；吞吐、峰值内存及撕裂仍需实机量测。I²C／I²S外设沿本地共享实现，不把物理引脚相同当作声音已验证。

底座SD电源43与默认UART0 TX冲突，CMake要求USB Serial/JTAG控制台，不能静默启用UART。原BSP的SD host helper虽接收slot参数，实际复制 `SDMMC_HOST_DEFAULT()`；本地保留这个实际默认及显式GPIO配置，没有按其注释强行改成slot0。

未初始化底座传感器总线GPIO40／41、IMU／温湿度、硬件MUTE GPIO1或电容home的应用回调；这些不因BSP头文件曾声明能力而变成已支持。没有复制睡眠、断电、充电、电池估算或原厂MCP。

## ILI9341 旧长度标记修正

固定BSP有11条真实参数行，其字节／顺序逐项保留，包括BGR 0x36=08和RGB565 0x3A=55。后面两行将0x11／0x29的 `data_bytes` 写为0x80，结束行写0xff，载荷却各只有1字节；同提交的现代ILI9341驱动会把这些字段直接作为发送长度，没有解释成延时标记。直接照抄会读取超出载荷的数据。

本地沿项目已有SDK DCS复用方式创建ST7789操作对象，对ILI9341分支替换init和sleep方法，避免发送SDK ST7789特有的RAMCTRL初始化。先保留ILI9341自身的sleep-out100ms及MADCTL／COLMOD前导，再发送11参数行；原尾部的0x11／0x29改为无参数DCS，sleep-out后显式等待120ms，结束行不发送。120ms采用所读ILI9341 sleep API的等待值，这是一项明确修正，不声称与旧表字节相同或已实物验证。

ST7789分支仍使用本机SDK自己的初始化。两分支都保持active-high共用复位、面板mirrorXY和同样的LVGL镜像配置；分支选择依据是原BSP的触控地址探测，不是独立面板ID认证。

## TT21100 解析边界

新轮询只读取原驱动规定的裸I²C两步报文：先2字节小端长度，再完整报文。每次I/O100ms，固定57字节上限；检查报文内重复长度、7字节头、每触点10字节、原始触点数和large-object／保留标志。仅单点type0按tip位判断接触，坐标只在有效接触时发布；多点不截断成1。没有沿用原驱动第二次read返回值未保存、直接剪裁count后访问记录等问题。

14字节、ID03的辅助按键报告只消费，不映射为应用操作、不伪造指针释放；此前有合法指针状态时保留它，否则等合法触点报告。空／复位／超长／损坏报文取消按压，避免将未知状态当正常松手点击。轮询不发送睡眠命令，也不在LVGL锁中无限重试。

**仍缺完整report-ID白名单和实际tip／event／FIFO抓包验收。** 当前来源的touch结构只命名tip等位，旧实现没有校验所有report类型；本地按已读结构做有界解析，不把它说成协议全覆盖、芯片身份认证或实机触摸通过。严格长度及空FIFO处理是否适用于所有BOX-3修订仍需真实设备验证。

## 2.16 方向遗漏修复

此前2.16只在面板表中保留MADCTL A0，却没有跟踪LVGL注册后的调用。当前 `esp_lvgl_port_add_disp()` 会立即调用rotation_update；默认false的swap／mirror会把CO5300的A0清成00。故“初始化表没改”不足以证明显示方向被保留。

本批在2.16编译分支中明确设置LVGL `swap_xy=true、mirror_y=true`，与A0的MV／MY位一致。1.75的默认00方向分支不变；触摸映射也没有在此次改动中再次变更。已重新构建2.16并核对当前输入；旧首次接入文档追加了这项修正。实际屏幕方向／触点对应仍未验收。
