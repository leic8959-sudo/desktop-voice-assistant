# 导航箭头加粗与读音修复

牛牛确认“导航箭头太细”，待机圆球不在本次调整范围。“直行”被合成成 zhí háng，本次仅调整导航合成输入为“直走”，屏幕保留“直行”原文。

## 修改

- `firmware/assistant_espidf/main/display_ui.cpp`：导航粒子从中心线分布改为沿线法向铺开，笔画目标宽约12像素；导航亮点使用2×2像素。仍使用768个粒子与原40ms帧周期，不增加点云缓存或动态分配。待机、普通对话和计时点云沿用原渲染。
- `firmware/assistant_espidf/main/version.txt`：0.3.17。
- `src/assistant_app/application/proactive_speech.py`：只有带 `nav_icon` 的导航播报合成文本将“直行”替换为“直走”；下发屏幕文字不变，普通播报不受影响。
- `tests/test_navigation_pronunciation.py`：覆盖导航合成/屏幕文字分离与普通播报保持原文。
