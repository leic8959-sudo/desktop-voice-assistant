# 企业控制台设计令牌

当前采用 Raycast / Arc 风格的深色 AI 控制台：

- 背景：`#07070a`
- 面板：`#101014`
- 次级面板：`#17171d`
- 边界：`#292932`
- 主强调：`#b8a4ff`
- 强调渐变：`#d1c6ff` -> `#977dff`
- 成功：`#79d9a7`
- 警告：`#f6c875`

## 结构规则

- 左侧导航固定，主区负责当前工作上下文。
- 总览只呈现判断所需信息，详情进入抽屉或独立页面。
- 所有状态必须同时有文字和颜色，不依赖颜色单独表达。
- Demo 数据必须标记为 `Demo 数据`，真实接口加载后切换为 `Live 数据`。
- 写入、发送、设备控制动作必须展示确认状态和审计入口。

## 页面拆分顺序

1. 总览
2. 连接器详情
3. 工作流详情
4. 审计日志
5. 权限与凭据
