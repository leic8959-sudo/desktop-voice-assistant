# 连接器配置

管理面板 API `GET /api/connectors` 会返回每个连接器的动作和 `configured` 状态，不会返回密钥值。

| 连接器 | 配置项 | 主要能力 |
| --- | --- | --- |
| Gmail | `gmail_client_id`、`gmail_client_secret`、`gmail_redirect_uri` | 搜索邮件、读取邮件、草稿和发送确认 |
| Google Calendar | `google_calendar_access_token` | 查询和创建日程 |
| Microsoft 365 日历 | `microsoft_calendar_access_token` | 查询和创建 Outlook 日程 |
| Microsoft 365 邮件 | `microsoft_calendar_access_token` | 搜索邮件、创建草稿 |
| Notion | `notion_access_token` | 搜索和创建知识页面 |
| GitHub | `github_access_token` | 搜索和创建 Issue |
| Slack | `slack_webhook_url` | 发送文本通知 |
| Todoist | `todoist_access_token` | 查询和创建任务 |
| 飞书机器人 | `feishu_webhook_url` | 发送文本通知 |
| 高德地图 | `amap_web_service_key` | 地点搜索、天气查询 |
| Home Assistant | `home_assistant_url`、`home_assistant_token` | 设备发现、状态和动作 |

写入、发送和设备控制动作必须带 `confirmation_id`。访问令牌和 Webhook 只通过本地配置或环境变量提供，不写入代码和前端响应。

Gmail OAuth 客户端配置也支持 `ASSISTANT_GMAIL_CLIENT_ID`、`ASSISTANT_GMAIL_CLIENT_SECRET`、`ASSISTANT_GMAIL_REDIRECT_URI` 和 `ASSISTANT_GMAIL_PROXY_URL` 环境变量。

Home Assistant 地址和令牌也支持 `ASSISTANT_HOME_ASSISTANT_URL`、`ASSISTANT_HOME_ASSISTANT_TOKEN`。
