## 查询合同

范围查询沿已有 device/status/due_at/task_id 索引，直接按 due_at、task_id 排序及游标前进，最多读取 limit+1，不使用 NULL 表达式排序、全库加载或 OFFSET。无范围时保留原 NULL 排序与分页合同。范围收到 NULL 游标返回空，不退回全库。

API 透传同名时间边界并由存储严格解析；Realtime、Chat 共用工具 schema 和提示词，查询“今天/明天”按 Asia/Shanghai 日界，传入当日 00:00+08:00 至次日 00:00+08:00，不在全库分页后内存筛选。

任务页默认不筛选，提供北京时间日期输入、应用、清除，并明确日期筛选不包含未设时间待办。输入是草稿，另行显示当前已经成功应用的日期；新筛选从首页读取，只有响应校验和呈现准备成功后提交筛选状态，失败恢复日期输入并保留原成功页内容与游标。
