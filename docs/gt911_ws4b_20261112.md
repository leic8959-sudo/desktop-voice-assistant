# 微雪 4B GT911 轮询接入与整板构建

本批推进已有 `waveshare-esp32-s3-touch-lcd-4b` 完整终端源码候选。该板GT911的复位／0x5d地址选择已由TCA9554 P5／P6完成，原通用驱动的RST／INT设置为NC。本批复用现有16位命令panel IO，新增固定容量轮询，移除本板对未安装GT911组件的依赖；没有安装、复制整套第三方触摸组件或替其它板型执行复位。

## 协议和状态边界

寄存器／8字节点格式对照Espressif GT911 1.2.1公开源码，固定提交 `4df6ea55593668302db2127b6b41760d5d1b5ea1` 已按Git blob核实，与此前归档源码逐字一致。本批仅借鉴协议事实，没有复制通用factory的GPIO／IRQ／休眠／坐标变换实现。

新增 `main/gt911_polling.h/.cpp`：初始化仅读取0x8140的4字节产品字段和0x8047配置字节，检查实际IO结果并记录观察值，不以这些字节宣布硬件身份或修订已确认。读取使用0x814e状态的ready位与低四位count，从0x814f读取0～5个完整8字节点，再向0x814e写0确认。最多40字节固定读取缓冲，完整保留五点数量，不截成一指后错误放行。

| 场景 | 行为 |
| --- | --- |
| 有效ready报告且payload／ACK均成功 | 发布坐标并保存已确认快照；count=0才是已确认松手 |
| 健康的not-ready状态 | 沿用上一份已确认快照，不清控制器状态，不猜测松手 |
| 首次尚无有效报告，或之前失败后仍not-ready | 返回未完成，保持消费者取消／等待释放，不能把空缓存当作真实松手 |
| 状态读取、payload或ACK失败 | 不发布本次报告，作废快照；消费者取消并重新等待真实零点报告 |
| count>5、按键／接近／保留状态位、重复track ID | 拒绝该报告，不把异常、多点或不支持输入转成普通释放／单点 |

ready报告的ACK错误向上传播，payload错误时也不会发布读到一半的数据。与参考驱动不同，not-ready不写清除，避免读后到达的新报告被清掉；不再依赖通用驱动缓存被上层读取或清空的副作用。两者都没有提供真实触摸状态保证：控制器若长期只返回not-ready，保留的按压快照仍可能过时，本批没有擅自设置超时来伪造松手，也未完成卡死检测。真实静止按压、释放节奏与故障恢复需实机验收。

轮询只有一个LVGL消费者；初始化在它启动前完成，借用IO的全局生命周期不变，不新增任务、动态队列或每次读分配。现有每次panel IO超时100ms保留；一次轮询可能有状态、坐标、ACK三次传输，不能称端到端100ms。

## 保留的板级路径

触摸仍由原TCA9554 P5/P6复位并选择0x5d，读取400kHz／16位寄存器。现有480×480界面只接受范围内一指，初始必须先释放，多指／越界／读取错误用INDEV_RESET取消动作。新的固定帧直接交给原消费者，没有新增镜像或坐标缩放。

原ST7701三线初始化、480×480 RGB／16MHz时序、帧／bounce缓冲、背光、ALDO1、TCA9554 PA、ES8311＋ES7210／24kHz／TDM4槽位、BOOT、完整自定义唤醒、AEC、自然插话、媒体、配网／绑定和双OTA保持原源码。该IO封装不提供GPIO复位、0x14回退、IRQ、按键或sleep API；BigSmart、CHD、Guition、P4等其它GT911入口继续各自依赖与原地址／复位策略，未迁移或登记通过。

## 剩余与范围

真实GT911固件的状态位、按键／接近报告、数据ready节奏、stationary press／release、重复track ID、ACK和bus错误、RST／INT选址波形、真实坐标／多指取消均未实机验收。原480RGB画面、供电／PA／音频／AEC／唤醒／自然插话／媒体／同板OTA也未由本批触摸源码替代验收。当前只有微雪1.8实物。

SDK强制UND与警告继续记录，退出0不等于可启动、零UND或干净发行环境。IDF共享root_managed_components锁元数据可能更新，事后快照独立保存。未Git写入、安装依赖、刷机、OTA、上传或发布。

源码数量、功能范围与构建相互独立：152个官方源码入口中4个仍有上轮明确标出的必需功能缺口，另36项无源码。这次GT911轮询只作用于微雪4B，不解决Guition或无PSRAM实验候选的完整唤醒／AEC／双OTA问题。

本板当前矩阵依赖状态从not_run更新为resolved_local_overrides；历史文档中缺GT911的预检结果继续保留。构建账本为2 passed_cached_sources／79 stale_cached_sources／3 failed_cached_sources／104 not_run，当前通过为微雪4B和Freenove；其它历史成功随完整main输入改变转stale，累计81官方变体曾缓存构建通过。188项本轮实机均not_run；4／148／36的源码功能范围分类保持不变，不把触摸接入当成完整硬件支持。
