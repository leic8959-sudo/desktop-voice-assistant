## 根因与恢复

使用`docker desktop restart --detach`先尝试恢复，15秒超时；`docker ps`、desktop status也超时。确认后端处于启动崩溃而非正常服务状态后，仅停止已核对可执行路径位于`C:\Program Files\Docker`的Docker Desktop/后端进程，不关闭其他WSL发行版、不重启Windows或小燕子网关。
