# 2026-11-02：语音三件套——人格卡、还珠梗、方言（抖音向）

为拍摄抖音宣传做的一组低成本高爆点功能：10 张人格卡、16 条固定彩蛋（含还珠格格梗和抖音互动梗）、4 张方言人格 + 按需方言。全部是网关侧提示词/配置，**固件不用重刷**，下次唤醒生效。

## 一、实现位置

- 新增 `persona_settings.py`：人格卡白名单、风格提示、彩蛋库、`persona-preference.json` 持久化。
- `llm_providers.build_instructions`：把当前人格卡、切换规则、方言规则、固定彩蛋、安全边界拼进系统提示（Realtime 与 chat 管道共用）。
- `assistant_runtime` / `control_api`：`GET /api/personas`、`PUT /api/persona`；`/api/status` 增加 `persona`，capabilities 增加 `personas`。
- `web/index.html` + `web/app.js`：后台面板新增「人格卡」下拉与保存。
- 测试：`tests/test_persona.py`（目录、保存/加载、非法值、提示词包含彩蛋/方言/边界）。全量回归 107 passed。

## 四、方言

- 4 张方言人格卡（东北/川渝/粤语/台湾）全程用对应方言。
- 其他人格可按需切换：说“用四川话说这句话”“粤语来一句”。
- 注意：方言是模型模仿的语气与词汇，不是专业方言 TTS 音色，个别字词发音仍取决于云端音色。

## 五、拍摄用法建议

1. **还珠情怀系列**：唤醒 → “皇阿玛” → 台词 → 追问“那紫薇呢”，做情怀回忆杀。
2. **方言挑战系列**：同一句话让东北/川渝/粤语/台湾四个版本各说一遍，天然有对比和重复观看。
3. **人格反差系列**：温柔陪伴和毒舌损友对同一问题的回答剪成左右分屏，评论区投票“你站哪个”。
4. **抖音互动系列**：结尾说“抖音”，让小燕子自己喊关注；或“点赞”“涨粉”彩蛋做结尾口播。
5. **切换演示**：视频里直接说“切换到傲娇模式”，展示即时人格切换（本次会话内生效）。

## 六、边界与已知限制

- 人格只改变语气和表达；工具调用、事实准确性、隐私和安全规则不变。
- 固定彩蛋依赖提示词约束，极端情况下可能被模型改写；如需 100% 稳定可以后续做网关侧文本拦截（拦截 STT 后直接回固定台词）。
- 面板切换是“下次唤醒生效”，当前会话保持原人格（对话内语音切换即时生效）。
- 人格/彩蛋会增加少量系统提示 token，对延迟影响可忽略。
