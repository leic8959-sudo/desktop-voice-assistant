# 微雪 C5 LCD 1.69 首次整板构建（2026-11-13）

本批推进已有 `waveshare-esp32-c5-touch-lcd-1.69` 源码入口，应用身份 `assistant_c5lcd169`。早期入口仅按固定小智工程的版本要求设置 SDK 6.1，因此在现有环境预检时停止；后续 Moji2 C5 已在本机 SDK 5.5.6 上完成真实整板构建，本批重新核对 1.69 所用 API 并建立独立目标构建。

## 范围与来源

正式源码只修改本板 manifest 的 IDF 范围为 `>=5.5.6,<5.6.0`，以及 registry 中本板的 `implementation_scope` 说明。不扩大到未经验证的其它 SDK 系列，不安装或迁移 SDK。全部 main 文件、原板引脚、显示／触摸、音频、固定唤醒、控制协议及其中人工决定、绑定、NVS 和 OTA 保持本批开始时内容。没有因构建限制改成纯按键或删除 AEC／自然插话／媒体／双 OTA。

固定小智来源仍为 v2.5.2 提交 `49b4380b3faa0ceadd28a3e78aaf0f311c46c57e`。重新核对 76 份前批源码／接口证据的 SHA256，以及带 Git blob 字段的内容；另保存当前 SDK 的 7 份头文件，覆盖 ST7789 声明、SPI／I²C／LEDC 及 C5 外设能力。声明存在只说明接口可用，实际目标构建结果单独记录。

厂家资料新增如下来源，原文及摘要存于本批 `manufacturer/`：

- [商品页](https://www.waveshare.net/shop/ESP32-C5-Touch-LCD-1.69.htm)明确列 16MB Flash、8MB PSRAM、ST7789V2 和 CST816T。这比此前只依据上游全局 Flash 默认值更直接，仍不是当前实物容量或芯片身份测量。
- [官方资料页](https://docs.waveshare.net/ESP32-C5-Touch-LCD-1.69/Resources-And-Documents/)关联厂家工程。其源码固定在 `4e2a31bce8b57169039e92da9f8e447a4f34c457`，完整非截断 tree 与六份 BSP／配置／许可按 Git blob 核对。
- 厂家该版 BSP manifest 声明 IDF `>=5.3`、esp32c5，并直接依赖／调用 `esp_lcd_touch_cst816s`。其显示及音频、扩展器引脚与当前候选一致。商品页的 CST816T 与驱动名 CST816S 分别记录，不把驱动名当成实际芯片料号，也不据相同 API 宣称所有 CST816 型号通用。
- 本地 CST816S 1.1.2 的初始化读取 0xA7 并打印，不用固定 S 型 ID 值作成功门槛。实际坐标路径继续由本地原代码读取 0x02 起五字节，保留 count／event／坐标及取消按压检查。厂家新例程的触摸复位是低／高各 200ms；当前候选沿用前批各 100ms，固定小智板类只设置扩展器方向并拉高，没有同样的复位脉冲。三者分别记录，当前时序仍待实机验证。
- 资料页还有标为 ST7262 的屏幕手册链接，与本板商品页的 ST7789V2 不一致，本批没有将它用作本板屏控协议依据。没有下载出厂固件、完整依赖包或安装厂家 BSP。

厂家 raw 源下载曾发生连接重置，随后改用同一固定 tree 的 GitHub blob API 读取成功并核对内容；没有关闭 TLS 校验。SDK 头文件记录脚本首次误把 ST7789 工厂声明当成直接位于 vendor 聚合头，返回退出 1；改为分别核对聚合头 include 与实际 ST7789 声明头后退出 0，不涉及固件改动。
