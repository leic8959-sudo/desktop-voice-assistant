# 跨服务工作流

## 会议出行规划

接口：`POST /api/workflows/meeting-travel`，查询日历会议地点并规划驾车路线。

## 会议纪要沉淀

接口：`POST /api/workflows/meeting-notes`，将会议标题和内容写入 Notion 指定父页面。该工作流是写入操作，必须携带 `confirmation_id`。

## 待办转 GitHub Issue

接口：`POST /api/workflows/github-issue`，将会议待办提交到指定仓库。该工作流是写入操作，必须携带 `confirmation_id`。

接口：`POST /api/workflows/todoist-task`，将会议待办创建为 Todoist 任务。该工作流是写入操作，必须携带 `confirmation_id`。
