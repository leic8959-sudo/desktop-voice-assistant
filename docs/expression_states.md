# AMOLED 表情状态

| 状态 | 视觉反馈 | 进入来源 | 退出规则 |
| --- | --- | --- | --- |
| `idle` | 黑底、蓝色双眼，随机间隔约2.6～5.1秒眨眼，闭合约140ms | 会话空闲 | 下一事件 |
| `listening` | 双眼睁开并轻微横向移动 | 按键或 WakeNet 唤醒 | `listen stop` 或服务端状态 |
| `thinking` | 眼睛缓慢移动、三个光点依次亮起 | 服务端思考阶段 | 下一状态 |
| `speaking` | 嘴形按本地待播PCM平均音量平滑变化 | 本地开始消费音频队列 | 本地队列结束标记/interrupt |
| `executing` / `search` | 眼睛移动、状态字幕 | 工具执行或搜索 | 工具完成 |
| `alert` / `error` | 黄色/红色边框、短文本卡 | 提醒或错误 | 新状态；通知卡至少保持 5 秒 |
| `notification` | 黄色边框、标题和到期时间 | 通知交付 | 保持5秒后恢复最近状态；用户开口或错误可提前打断 |

动画由33ms的 LVGL timer 在显示线程中更新，不重复调用 BSP lock。状态更新来自其他任务时使用显示锁。嘴形按音量开合，不代表逐字/音素唇同步。字体使用实际LVGL9.6组件内的思源黑体16px CJK；文本卡有固定宽高。通知界面更新成功后才允许协议层发送ACK，不能把它解释成用户已阅读或已完成待办。
