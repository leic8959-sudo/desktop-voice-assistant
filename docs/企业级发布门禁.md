# 企业级发布门禁

## 已具备

- 配置校验和环境变量密钥覆盖
- Bearer 认证、恒定时间令牌比较和失败审计
- API 请求 ID、结构化审计、日志轮转和单实例限流
- `/health` 健康检查、Docker Compose 基础部署
- 117 项现有 Python 测试通过

## 发布前必须完成

- 真实凭据全部撤销轮换，并确认没有进入 Git 历史、证据包和运行时快照
- TLS 终止和可信代理配置
- 用户、角色、令牌过期与撤销，而不是共享设备令牌
- 多实例共享限流和审计存储
- 数据库迁移、备份恢复和升级回滚演练
- 固件、云服务、家庭控制和 Gmail 的生产授权与现场验收

在“发布前必须完成”全部通过前，项目只能作为本地或可信局域网开发版本使用。
