## 共用屏幕与原板级差异

将上批 `sensecap_panel.cpp/.h` 重命名为 `spd2010_qspi_panel.cpp/.h`，创建函数与日志tag随之更名。按原文件内容替换这些名字后逐字比较一致，没有另写一套屏幕流程。原402条默认表、NC软件01等20ms、FF201000用户页／MADCTL00／COLMOD55前导、分页规则、mirror位1／0、RGB565缓冲／窗口和IO完成通知保持；SenseCAP继续用同一实现及原工厂保护分区。

1.46仍QSPI2 mode3／40MHz，CS21／CLK40／D0..3=46/45/42/41；TCA9554 P0/P1原复位、高低高时序与GPIO5背光保持。屏幕硬件swap_xy即使false也不支持，本轮跳过显式false调用并设置LVGL软件旋转flag，rotation0保持原生轴，增加一份20行旋转条带；原四像素X对齐、双20行DMA／字节交换不改。

原数字音频为16kHz RIGHT、32位输入右移12并饱和，24kHz LEFT、32位PCM5101输出；无PA的真实PCM软件静音、完整唤醒／AEC／自然插话、媒体／绑定／NVS／提醒／双OTA均保持。GPIO0操作、PWR6新按住5秒后释放GPIO7保持、电池／RTC／传感器未知状态不改；本轮没有通过删掉语音功能适配。

## SPD2010 触摸协议与有界处理

新增 `spd2010_touch.cpp/.h`，保留Espressif版权并沿用SPD2010 Apache-2.0全文。借用0x53／100kHz／命令位0／禁用控制阶段的panel IO，每次IO100ms，INT4只作输入轮询，不建立ISR；复位由既有TCA完成，不猜ESP复位GPIO。初始化按参考读取2600的18字节固件信息，只记录观察值，不用它证明真实身份。

| 状态／流程 | 处理 |
| --- | --- |
| 2000读4字节status／length | 解析原点／手势位、BIOS／CPU／cpu_run和长度 |
| BIOS | clear `02 00 01 00` 后 CPU start `04 00 01 00`；不把握手当释放 |
| CPU模式 | point mode `50 00 00 00`、touch start `46 00 00 00`、clear；等待后续确认释放 |
| cpu_run且length0 | clear成功后发布零点，沿参考处理；真实含义待设备确认 |
| 点报告 | 0003读5..64字节，4字节头后最多10个6字节点，保留原始count、12位XY、ID和weight；校验长度／ID／重复ID，不先截成一点 |
| HDP完成 | FC02读8字节，status82才检查clear成功并发布；未知status返回错误 |
| HDP剩余包 | status00按声明1..64字节读剩余，最多8次status／累计512字节，一秒在迭代间检查；每次IO仍可能另占100ms，因此不是严格端到端一秒 |
| 续包限制 | 原驱动排空但丢弃续包内容，未给组包合同；新实现同样有界排空到确认，但发生续包时取消首报告，不猜测其完整性 |
| 空闲／aux | 不伪造释放；只复用已确认快照，初次／故障后没有确认帧时返回未完成；长空闲仍可能保留过期按压 |
| UI消费者 | 初次／故障恢复需零点释放，只接受412内单点；多指、越界、错误或不支持报告用INDEV_RESET取消，手势不触发产品动作 |

所有协议间200us等待保留，不按轮询动态分配内存。weight0没有充分释放依据，不擅自等同松手。参考协议未提供CRC／包序保证，续包组装、零长度释放、静止／长按／ready节奏、BIOS／CPU切换、IRQ、ACK故障和真实坐标都需实际资料／包迹及硬件验收。正常固件若常发续包，当前实现可能持续拒绝报告；这个兼容性缺口没有隐藏。

只有现有微雪1.8实物。1.46实际Flash／PSRAM、TCA复位／电源键、402条表／40MHz／颜色／可视范围／软件旋转内存峰值、数字麦克风RIGHT槽／PCM5101 LEFT槽／时钟／静音、AEC／唤醒／自然插话、媒体／绑定／提醒／同板OTA均未实机验收；RTC／传感器／电池遥测等原缺项保留。
