# 第三方连接器架构

所有 Gmail、日历、飞书、地图、Home Assistant 和企业系统接入都应实现统一 Connector 契约，不直接把供应商 SDK 调用写进 `gateway.py`。

每个连接器必须声明：

- 稳定的 `connector_id`、版本和可用动作
- OAuth 权限范围
- 每个动作需要的权限：读取、写入、发送或设备控制
- 写操作是否必须携带一次性确认 ID

调用流程：

```text
用户授权 -> OAuthStore 保存凭据 -> ConnectorRegistry 注册
    -> 解析动作和权限 -> 检查确认 -> 调用供应商 -> 记录审计
```

当前设备令牌会映射为 `admin` Principal。第三方连接器应使用独立的 OAuth grant，不能复用设备令牌或把供应商密钥写入连接器实例。

当前已落地连接器：Gmail、Google Calendar、Microsoft 365 日历、Microsoft 365 邮件、飞书机器人、Slack、高德地图、Home Assistant、Notion、GitHub 和 Todoist。所有写入、发送和设备控制动作默认要求预览确认，读操作可直接执行。
