# 伊迪斯后台面板优化方案

日期：2026-11-13，Asia/Shanghai。牛牛要求“后台面板还需要优化制定方案创建luna执行”。主任务制定范围，Luna 实施，主任务检查最终源码及实际页面。

## 现状和目标

当前 `/admin` 提供真实状态、连接器、工作流和审计入口；采用既定深色紫色风格。侧栏14个入口同权重排列，总览直接展开全部连接器、工作流及最多30条审计，首屏缺少日常入口；认证工具条和维护边界文字占据主要空间。运行状态没有直接显示当前模型、设备固件和联网搜索开关。布局依赖共享 CSS，修改必须检查其他独立页面。

本次沿用现有风格和原生 HTML/CSS/JS，优化信息层级、状态可信度与常用任务路径。所有已有入口、真实接口、认证和写入确认保留；不扩展产品能力，不修改语音、固件、设备绑定、数据库和后端，不运行真实家居/电脑动作或第三方写入。

## 实施范围

主要修改 `web/admin_console_demo.html`、`web/admin_console.css`、`web/admin_console.js`；确有需要才小改 `web/console_settings.js`。保留共享 API、既有确认机制和设置保存行为。CSS新增布局尽量限定 `.app` 或控制台特有类，避免独立页面样式回归。不重写其他功能页。

### 1. 导航和页面结构

- 侧栏分为日常使用、连接与设备、系统管理；全部既有入口保持可达。
- 总览、工作流、审计、权限与凭据、系统设置、助手继续使用现有路由，刷新/前后退与 `aria-current` 正确。
- 移动端采用明确的菜单开关和可收起导航，具备 `aria-expanded`、Esc关闭和点击路由关闭；不用14个平级入口撑长首屏。
- 页面标题、说明与主要动作形成清晰标题栏；保留品牌“伊迪斯”。

### 2. 总览工作台

- 首屏以“伊迪斯工作台”为中心，展示真实网关、在线设备、当前模型、Web搜索开关。搜索只写已开启/已关闭/未知，不假称已验证联网；云会话未连接显示待机，不标故障。
- 提供六个常用直达入口：个人助手、设备管理、提醒与主动助理、记忆管理、互联网点歌、连接器中心。使用现有页面，不触发业务操作。
- 设备摘要读取已获取的 `/api/devices`，显示真实在线状态与固件，未知值明确。禁用或离线状态不要伪装在线。
- 总览连接器与工作流保留精简可读摘要和详情入口；审计在总览只显示最近5条，审计路由显示服务端返回的全部有界记录。搜索/筛选存在时不得让隐藏项造成错误“无结果”，必须支持展开完整匹配或明确进入详情。
- 总览不新增业务网络请求，沿用现有四项获取和30秒可见页面刷新。

### 3. 认证与状态反馈

- 已认证时把令牌输入收进可展开的“切换认证”，保留本机登录和已有Cookie路径；未认证时提供清晰操作。
- 加载中、部分失败、成功、快照过期均有明确文字，保留分区重试及旧响应代次保护；错误不能显示完整实时状态。
- `401` 清理私有数据、详情和计时刷新，保留原行为；令牌不进URL或浏览器存储。
- 技术解释放入适合的详情/帮助，不在常用操作主路径堆叠实现细节。

### 4. 详情与表单

- 统一抽屉间距、表单字段和结果区，长内容可滚动，关闭/Esc/焦点恢复保持有效。
- 优化工作流表单的枚举：Notion父级类型、Todoist优先级使用可点击选择项，正文用多行输入，仍使用现有参数与确认接口。
- 不缩减现有写入预览、确认、鉴权边界，不增加直接写入入口。

## 验收要求

1. 桌面1440×900和窄屏390×844无页面横向溢出；总览首屏主要状态与常用入口清楚，菜单可用。
2. 未认证/已认证、在线/离线、云待机/活动、搜索开/关/缺字段、空数据、部分失败和401均按真实字段显示，无示例成功数据。
3. 所有既有入口可达，hash深链/前后退、详情关闭和审计筛选保持可用；总览限制数量不截断审计详情。
4. 保留现有业务接口、确认流程和认证，不新增自动云查询/自动写入；缺字段用未知，不能推断连接已验证。
5. 共用CSS不破坏连接器、音乐、设备等独立页面。静态审阅比较本次修改前备份，保留用户/其他任务既有改动。
6. 交付实施文档，列明文件、实际核对、未验收项。本机服务运行中直接读取根 `web/`，静态编辑可能立即生效；不重启网关，不刷新冻结运行清单或宣称已生产部署。
