# 点云自由形态调整

日期：2026-11-04（Asia/Shanghai）。牛牛认可“点云形态”方向，并指出待机、聆听、正在回答太规则。本轮调整这三个状态的预览及固件源码，不构建或发布OTA，保留当前已安装0.3.9和绑定凭据。

## 改动

- 待机：由规则球壳改成内部有体积层次、局部疏密不同的点团；慢速、非对称漂移。
- 聆听：使用稍强的局部流动和聚散，避免固定波纹 / 规则球形。没有接入新的麦克风电平接口，不宣称听取当前环境声音来驱动画面。
- 正在回答：点云流动受既有播放包络影响，局部伸展与收缩，避免全体等幅缩放。预览使用示例包络，不采集音频。
- 点位使用连续确定的相位场，不在每帧生成随机数，避免噪点跳闪。自由形态系数平滑过渡；其他状态仍保留已有语义形态。
- 固件复用已有768个粒子、正弦查表和固定缓冲，没有依赖、新服务或每帧对象分配；共用流动相位、漂移和强度在循环外计算。增加的逐粒子计算仍可能影响帧预算，实际性能未编译/实机验证。

## 文件与范围

- 修改 `firmware/assistant_espidf/main/display_ui.cpp`：一个自由形态混合系数、体积密度、三维连续流场、非匀速转动及亮度层次。保留语音 / 提醒 / 卡片调度、文字、按钮、配对和协议。
- 更新聊天中的 `point-cloud-screen-styles.html`：三种状态采用自由流动；默认选择正在回答，保留“播放动效 / 暂停动效”、原17个状态、样式对照和减弱动态支持。添加“自由程度”设计调整项。
- 预览为风格示意，浏览器数学实现与设备查表 / 采样 / 原先扰动并非像素等价，不把预览帧率或画面当成实际固件验收。
- 编辑前副本：`%TEMP%/xiaoyanzi-free-cloud-20261104-before`。未改规则文件和人工决策代码，保留无关工作区改动。
