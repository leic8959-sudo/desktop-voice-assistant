# 设备配对协议

## 设备发起

匿名 `POST /api/devices/pairing/device-start`，JSON 为 `{"device_nonce":"硬件随机生成的16至128字符"}`。返回 `pairing_id`、`pairing_code`、`expires_at`。同一 nonce 的有效待绑定会话可重试，默认有效期十分钟。

## 后台绑定

管理员调用 `POST /api/devices/pairing/claim`，JSON 为 `{"code":"482913"}`。当前仅支持 local 工作区，服务器生成设备 ID；响应不包含设备凭据。旧的按会话 confirm 接口保留兼容，其五次失败限制不代表按码 claim 具备相同的计数限制。

## 设备领取

匿名 `POST /api/devices/pairing/{pairing_id}/device-result`，JSON 为 `{"code":"482913","device_nonce":"发起时的相同nonce"}`。后台绑定后两分钟内允许幂等重试领取同一凭据，以容忍响应丢失。未绑定、nonce 不符、过期或撤销均不得领取。设备保存 NVS 后使用该凭据连接 `/device/v1/`。

## 撤销和权限

管理员通过 `POST /api/devices/{device_id}/unpair` 撤销，服务端关闭对应连接并拒绝后续认证。设备凭据可用于设备连接和固件下载，不具有后台管理权限。

## 当前部署边界

- JSON 原子快照只支持单进程本地部署，最多保存256条会话；不是企业多实例或多租户实现。
- 快照包含长期凭据，应限制运行目录访问；当前未实现凭据加密和轮换。
- 固件使用硬件随机 nonce、10秒请求超时、3秒轮询及有限等待；失败或过期后提示重启重试。
- 普通日志不得输出配对码、nonce 或凭据；首次配对屏幕、NVS 保存和断电重连仍需完整真机验收。
