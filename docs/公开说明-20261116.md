# 伊迪斯公开说明

日期：2026-11-16，Asia/Shanghai。

伊迪斯是跑在自己电脑上的桌面语音助手。浏览器是基础入口，ESP32 是可选终端。它不是云端托管服务，也不需要租赁服务器。

## 现在可以看什么

- Python 网关、Web 控制台、个人事务和记忆源码。
- ESP32-S3 固件源码和板级适配记录。
- 历史验收文档。文档描述的是当时的检查，不是对当前提交的验收结论。

## 现在不能当成什么

- 不是陌生人开箱即用的安装包。首次使用需要自己准备 Python 3.12、模型账号和本地配置。
- 不是离线语音助手。语音识别、对话和合成默认走云端账号，会产生费用。
- 不是多用户、多租户或可暴露公网的服务。当前边界见 `SECURITY.md`。
- 仓库许可证不覆盖字体、ESP-SR、语音模型、小米集成、云端音色和音乐内容。详见 `NOTICE`。

## 本轮公开前处理

- 原创部分使用 Apache-2.0。
- 合成唤醒问候音没有再分发依据，已从仓库索引移除。代码在文件缺失时继续运行，只是不使用缓存首响。
- 历史文档中的样机标识和局域网地址已改为泛称。真实配置、运行数据和录音本来就不入库。
- 未提交的本机开发改动没有并入这次公开提交。
