## 已接好的交互（源码层面）

- 导航以 `data-route` 和明确 `href` 为标识，hash 路由支持直接访问、刷新与前后退；连接器、设备为已有独立页面。未知路由回到总览。
- 总览、工作流、审计、权限、设置和助手入口有明确视图，标题按路由更新。助手不再嵌入总览。
- 状态、连接器、审计、设备四区独立接收结果，失败区有错误和重试；成功区不因其他区失败而丢弃。重试和刷新共用忙碌门闩；认证变动递增代次、取消未完成请求，旧响应不能覆盖新认证数据。
- HTTP 401 清空数据、详情和令牌并停止网络轮询；已有 Cookie 会话无需填写令牌。本机登录调用现有 `/api/auth/local-login`，拒绝时提示实际访问限制。令牌只在当前密码输入框和请求生命周期内使用，不写浏览器存储或 URL。
- 元数据请求 12 秒超时，工作流查询 30 秒超时。控制台正常每 30 秒刷新；后台页面及打开详情期间暂停轮询；45 秒后降级为过期快照，错误或更新中不会继续显示完整 Live 标记。离页清空私有状态，浏览器缓存返回时重新加载。
- 连接器和工作流搜索、审计状态 / 文本筛选在刷新重绘后保持。审计展示服务端返回的全部近期条目，支持 2xx 成功、失败 / 拦截及未知三类；HTTP 成功不包装成外部业务成功。
- 全部工作流由服务端 `id` 动态生成，不再把两张静态卡按位置套用。展示实际 `required_connectors`、`ready`、`read_only`，不编造步骤、执行时间或历史。
- “会议出行规划”配置就绪时提供日历来源、时间范围及出发坐标表单，时间转换为带时区 ISO 8601，再调用现有只读接口。仅用户手动提交会触发外部读取；本轮没有实际提交查询。开始执行后不因填写时间超过快照时效而拒绝，只读请求由服务端校验实际配置和认证。
- 桥接、云语音会话和语音设备会话按字段名对应；无活动云会话不标成系统故障。在线 / 返回设备数来自 `/api/devices`，没有把布尔状态伪装成数量。
- 抽屉采用原生 `dialog.showModal()` 提供遮罩和焦点限制，支持关闭按钮、Esc、遮罩关闭及关闭后恢复焦点。布局仅一套基础 CSS 和连接器局部 CSS。

## 额外发现与处理

`gateway.py` 的 `security_headers` 对页面统一返回 `X-Frame-Options: DENY`，会拦截原助手 iframe；`web/app.js` 的 `connectApi` 也要求单独填写设备令牌。本轮使用明确的助手独立页面入口，提示其现有认证要求，没有放宽安全头或修改助手语音链路。不能声称控制台 Cookie 已自动打通现有助手。

## 审计边界

新记录由 `record` 写入 UTC 带时区时间戳。旧记录缺失时间或无时区时显示“时间未记录 / 无时区”，不构造“刚刚”或今日总量。

近期读取仅覆盖当前 `audit.log` 尾部 65,536 字节，额外最多读取 1 字节判断窗口起点是否残行，返回最多 30 条完整行；窗口起点残行和末尾未写完行跳过。极长记录可能不在结果中。响应公开 `limit`、`max_bytes` 和 `truncated` 说明范围；不遍历轮转历史。原日志轮转策略保留。
