# 连接器与工作流首轮闭环实施记录

日期：2026-11-04（Asia/Shanghai）。本轮仅修改本地源码与文档，没有重启网关、访问真实第三方写入接口、解绑设备或读取凭据值。

## 修改范围

- `src/assistant_app/infrastructure/confirmations.py`：新增单实例进程内确认存储。凭证由服务端生成，默认 5 分钟过期，绑定管理员主体、动作和规范化参数；执行时单次消费，参数变化、主体变化和过期均失效。相同凭证并发执行返回“进行中”，已完成 / 失败 / 结果待核实的凭证返回原结果。上限 256 条，按过期时间清理；不宣称多实例持久化幂等。
- `src/assistant_app/integrations/registry.py`、`application/meeting_notes.py`、`github_issue.py`、`todoist_task.py`：写动作要求 `confirmation_verified=True`，不再接受任意非空字符串作为确认。
- `control_api.py`：新增工作流 `prepare` 接口、通用写动作 `prepare` 接口、只读连接检查接口；三个指定工作流改为服务端凭证校验后执行，超时 / 网络异常返回“结果待核实”且不自动重试，成功结果带 `completed` 状态。Webhook 连接器没有发送测试入口。
- `web/connectors.js`、`web/connectors.css`：复用真实 Gmail 状态、OAuth 发起和刷新接口；区分“未配置 / 已配置未授权 / 已授权”，为安全只读适配器提供手动检查，Webhook 显示不支持无副作用测试。
- `web/admin_console.js`：会议纪要、GitHub Issue、Todoist 工作流提供参数表单、服务端预览、明确确认和结果展示；工作流仍由服务端动态返回。

## 接口边界

- `POST /api/workflows/{workflow_id}/prepare` 只生成预览和短期确认凭证，不调用第三方。
- `POST /api/workflows/{workflow_id}` 执行时校验凭证和参数哈希；重复提交返回原结果或 202“执行中”。外部结果未知时不重试。
- `POST /api/connectors/{connector_id}/{action}/prepare` 只适用于声明需要确认的动作；`POST /api/connectors/{connector_id}/{action}` 的写动作必须使用该凭证。
- `POST /api/connectors/{connector_id}/check` 只调用已声明的只读动作。连接检查成功表示本次读取成功，不代表长期健康；Webhook 明确不支持发送测试。
- Gmail 状态 / OAuth 继续使用 `gmail_api.py` 的既有 DPAPI 与回调流程，没有复制 OAuth 或凭据存储。Google/Microsoft 通用 OAuth、Notion/GitHub/Todoist 等凭据保存流程仍由服务端配置提供，本轮不伪造一键授权。
