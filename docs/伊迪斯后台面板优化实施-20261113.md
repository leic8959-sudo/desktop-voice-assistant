日期：2026-11-13，Asia/Shanghai。依据 `docs/伊迪斯后台面板优化方案-20261113.md` 实施，Luna 负责静态前端调整，主任务负责浏览器与运行页面验收。

- `web/admin_console_demo.html`：导航分组、移动菜单、标题操作栏、折叠认证、四项运行摘要、六个常用入口、折叠统计、设备摘要及精简列表说明。
- `web/admin_console.css`：保留深色紫色视觉；新增工作台和窄屏布局。工作台规则限定 `.app`，抽屉新增规则限定 `#detail-drawer`，没有改写其他功能页。
- `web/admin_console.js`：真实状态映射、设备固件摘要、列表展示数量与完整匹配、路由更新时重绘筛选、认证折叠及菜单交互、表单枚举与多行正文。

- 编辑前四个目标文件备份在 `runtime/review-backups/admin-panel-20261113-luna/`。保留原有“伊迪斯”品牌改名；没有覆盖连接中心及其他并发改动。

## 方案实施对应

### 导航与层级

原有14个导航入口全部保留，分成日常使用、连接与设备、系统管理。总览标题改为“伊迪斯工作台”，主要刷新动作放在标题右侧。原有 hash 路由及 `aria-current` 更新继续使用；导航改变时重新计算总览/详情展示数量。

620px 及以下使用明确“菜单”按钮，`aria-controls` 指向主导航，`aria-expanded` 同步展开状态；点击任意导航链接或品牌链接收起，Esc 收起并把焦点交还菜单按钮。菜单内容自身有高度限制和滚动区域。桌面侧栏仍可滚动。

### 工作台与真实状态

首屏四项摘要只消费既有状态：

| 内容 | 字段与行为 |
| --- | --- |
| 网关 | `status.bridge.running` 严格布尔判断，缺失为未知 |
| 云语音 | `status.cloud.connected`：true 活动中，false 待机，缺失未知 |
| 当前模型 | `status.bridge.model` 与 `llm_provider`，缺失未知 |
| Web搜索 | `status.capabilities.web_search`：严格布尔对应已开启/已关闭，缺失未知；保留“配置开关，不代表联网已验证”说明 |
| 在线设备 | 已获取的 `devices.items`；沿用旧网关过滤离线默认配置项的规则，显式禁用设备不计在线 |
| 设备固件 | `devices.items[].firmware`，缺失未知；摘要最多3台，可进入设备管理查看全部 |

状态/设备数据更新中、读取失败或过期时，首屏主值附带旧快照/过期标记；分区仍展示读取时间及重试按钮。移除原“Live 数据”措辞，整体状态分别显示正在更新、近期接口快照、部分读取失败、读取失败、快照过期和等待认证。

常用入口共6个：个人助手 `assistant.html`、设备管理 `devices.html`、提醒与主动助理 `productivity.html`、记忆管理 `memory.html`、互联网点歌 `music.html`、连接器中心 `connectors.html`。均为已有静态页面的链接，不触发业务动作。

连接器与工作流在总览默认各展示4项，附总数和详情入口；所有数据行仍参与搜索，查询时显示全部匹配，避免把摘要之外的项目误报为无结果。工作流路由默认显示全部工作流。连接器使用现有 `configured` 字段，已配置仍明确未验证连接，缺字段为配置未知。

审计沿用字符串JSON与对象两种记录解析，先筛选再取总览最近5条；`#/audit` 显示服务端本次返回的全部匹配记录。筛选条件在切换路由后保留，说明文字展示返回数、匹配数及当前可见数量，仍保留有限尾部窗口的含义。

### 认证与详情

认证工具收进原生 `details`。首次取得认证数据时收起，标题为“切换认证”；失效或切换输入后恢复登录入口。用户主动展开后不会被定时状态渲染强制收起。本机登录、Cookie和令牌认证路径保持原样；令牌只在输入框中使用。

401清空数据、抽屉内容、设置和刷新计时，取消请求及旧响应代次保护均沿用。API统一超时、30秒可见页面刷新、详情打开时暂停刷新和页面隐藏暂停机制保持。

抽屉继续使用原生dialog，保留关闭按钮、Esc和焦点恢复；统一字段间距，长结果区滚动。Notion父级类型改为page/database选择框；Todoist优先级改为1—4选择框；Notion正文及GitHub Issue正文改为多行输入。字段名和JSON参数、prepare预览及确认接口、执行超时和禁止自动重试行为没有改变，未增加直接写入入口。
