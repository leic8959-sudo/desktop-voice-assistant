# 小燕子仓库备份与恢复说明

2026-11-08，按牛牛要求将现有项目源码整理到 GitHub 私有仓库 `desktop-voice-assistant`。这是源码版本管理，私人数据仍留在本机。上传不改变正在运行的网关、设备固件或第三方账号状态。

## 上传内容

- Python 网关、个人事务核心、连接器和应用服务。
- Web 控制台及静态资源。
- `firmware/assistant_espidf` 自有固件源码、组件声明、依赖锁和默认构建配置。
- Python、JavaScript 和 C++ 测试源码、维护工具、迁移 SQL、Docker 配置。
- 项目说明和历史交付文档；字体及其原始授权文件、合成唤醒问候资源。

## 仅保留本机的内容

`.gitignore` 排除真实配置、环境变量文件、`runtime/`、`evidence/` 原始诊断资料、私人记忆和数据库、授权快照、录音、设备备份、生成的固件二进制、SDK/组件下载目录、构建缓存及下载的烧录工具。它们不是远程仓库的恢复来源。

历史文档中的 `runtime/`、`evidence/`、固件二进制和本机绝对路径通常指本地验收资料；仓库不保证这些链接在 GitHub 可打开。需要恢复同一台设备的记忆、配对或账号授权时，另行使用本地受保护备份，不能把它们提交到仓库。主程序的第三方组件与字体各自沿用其许可；本次未为整个项目擅自指定开源许可证。

## 新环境恢复

1. 克隆私有仓库。Python 依赖由牛牛按 `requirements.txt` 自行安装，本次上传不会安装任何依赖。
2. 根据 `config.example.json` 或 `python tools/init_config.py --lan-ip <电脑局域网IP>` 准备本地配置；填写真实服务凭据，保持 `config.local.json` 不被 Git 跟踪。需要环境变量时参考 `.env.example`。
3. `runtime/` 不在仓库中。迁移现有用户状态前先确认目标目录和设备身份，按 SQLite backup API 生成/恢复一致快照；新环境空目录会创建新状态，不会自动找回旧记忆。
4. 使用项目待办前，按 [项目与日常事务管家首轮交付](项目与日常事务管家首轮交付-20261107.md) 执行显式离线迁移；普通待办和记忆不需要该项目迁移。不要将未迁移状态当成数据丢失。
5. 通常使用 `start.ps1` 或 `python gateway.py --config config.local.json` 启动工作区源码。它会包含本次所有源码功能，与本机独立记忆候选入口不是同一个版本；首次启动和设备 OTA 应在维护窗口分别核对。上传不会自动启动服务或升级设备。
6. 固件依赖见 `firmware/assistant_espidf/main/idf_component.yml`、`dependencies.lock` 和 `sdkconfig.defaults`。构建方法见 `tools/build_firmware.ps1`，用户自行准备 ESP-IDF/Docker；不上传 SDK 和 `managed_components`。构建、烧录和设备验收是独立步骤。
