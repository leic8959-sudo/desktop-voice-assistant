# 设备偏好与完成提醒实施记录

日期：2026-11-04（Asia/Shanghai）。牛牛要求在保留 desk-1770bd2934c31b2f 绑定、凭据和已安装 0.3.10 的前提下完成本地实现。本轮没有重启网关、刷写固件、重新配对、擦除 NVS 或发布 OTA。

## 已实现

- 新增 `src/assistant_app/application/device_preferences.py`：设备音量、提醒音量、分别静音、免打扰、跨午夜安静时段、亮度、夜间亮度/时段和熄屏秒数白名单。使用 `device-preferences.json` 原子保存，字段和范围校验，不读取秘密。
- 新增 `GET/PUT /api/device/preferences`。保存沿用管理员同源认证、请求限流和屏幕反馈；设备在线时通过既有 WebSocket 下发，返回 `sent_devices` 与设备应用回执边界。
- `GET /api/screen/state` 增加设备偏好、设备回执、完成提醒和电量状态；增加 `/api/screen/completions` 查询和 `/api/screen/completions/{id}/ack` 已读接口。
- 桌面工具页新增可操作的音频/免打扰/屏幕表单、未读完成提醒卡片和电量未知提示。安静时间按 Asia/Shanghai 计算并传递 `quiet_active`；UTC 仍用于事件时间和租约。
- 固件复用已有 `esp_codec_dev_set_out_vol`、`esp_codec_dev_set_out_mute` 与 `bsp_display_brightness_set`。对话音频和提醒音频选择不同音量/静音字段；免打扰只阻止提示音调度，不中断语音、清空音频队列或改变计时状态。已有 8 秒/20 秒/60 秒提示音限频和过期队列保留。
- 固件在空闲、无卡片时按 `screen_off_seconds` 熄屏；状态、卡片、偏好下发和卡片按钮活动会恢复当前亮度。该恢复路径复用现有 LVGL/BSP，不抢占 BOOT 语音入口。
- 固件 `hello`/后台状态明确上报电量 `unknown`，来源为 `AXP2101_readback_unavailable`。当前工程没有可复用的 AXP2101 读寄存器接口；没有新增 I2C 探测、改电源寄存器或伪造百分比。
- 每个统一操作终态建立最多 32 条、24 小时 TTL 的内存完成提醒，区分完成、平台观察、未知、失败、拦截等状态；标记已读不改变任务状态。既有计时 ID/revision、服务器租约 ACK 和幂等流程保留。

## 完成事件边界

| 结果 | 屏幕/后台状态 | 声音 |
| --- | --- | --- |
| 服务明确返回完成 | `completed`/专用完成状态 | 仅既有错误/计时/提醒提示音规则，不为普通查询加声音 |
| 平台观察到目标状态 | `observed` | 不把平台状态当作物理确认 |
| 只接受请求、等待确认 | `processing`/`pending_confirmation` | 不提示完成 |
| 失败或权限拦截 | `error`/`blocked` | 复用错误短音及 60 秒冷却 |
| 结果待核实 | `unknown` | 可见未读卡保留，避免 HTTP 200/提交成功被包装成完成 |

倒计时结束由现有 `timer-{id}-{revision}` 卡片、`finished` 状态和计时提示音去重；忙碌或免打扰时卡片继续保留，声音可被延后或静音。重连会重新发送当前计时/提醒快照；完成提醒记录本轮为进程内有界 TTL，服务重启后的权威状态仍以任务/计时存储查询为准。
