# 聆听点云稳定调整

牛牛反馈：回答结束、等待继续说话时点云旋转明显，观感飘忽。本轮仅修改 `firmware/assistant_espidf/main/display_ui.cpp` 点云动画，不改语音状态机、麦克风、配对、提醒或设备配置。

源码发现两处直接相关因素：原流场相位使用“累计时间 × 当前状态速度”，状态切换会改变相位位置，运行时间越长切换越不稳定；原聆听流场强度由11增加到16，并增加横向拉伸。

修改为独立连续累加流场相位。聆听状态沿用原平滑过渡，稳定后旋转速度系数降至5%，形态时钟/漂移/倾斜/扭曲幅度系数降至15%，流场强度由16降至2，横向拉伸由18%降至4%，纵向压缩由10%降至3%。保留非规则体积点团和微小流动，不新增逐帧分配或粒子。这里的比例是源码参数变化，不是设备观感或实测帧率结论。

实际检查：`Get-Content`、`rg -n` 读取状态、动画和相关指导文件；`git diff --no-index` 对编辑前副本复核范围；`git diff --no-index --check` 检查差异空白。目录不是Git仓库，无Git写操作。编辑前副本位于系统临时目录 `xiaoyanzi-listening-cloud-20261104-before/display_ui.cpp`。

按当前默认规则未运行测试、构建、固件编译、长期服务或OTA，未安装依赖。设备上的0.3.10尚未包含此调整，当前只是本地源码修改；需要构建并安装新固件后才会改变实机画面。没有提交、上传或发布。
