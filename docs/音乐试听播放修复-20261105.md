# 音乐试听播放修复（2026-11-05）

牛牛明确选择“播放试听，并简短说明是试听”。此选择替代此前拒绝试听的策略。改动已于北京时间 18:20 左右重载到本机网关及 `xiaoyanzi-music-assistant` 容器；固件仍为 0.3.15，未执行 OTA。

## 原因与修改

此前并不是已经播放过试听：音乐扩展在识别到 preview 后只返回元数据、不交付 URL，随后释放租约；网关也主动拒绝 preview。所以 QQ 即使提供了30秒试听，小燕子也完全不会播放。

- `tools/music_assistant_player/player.py`：试听也生成现有正式队列的音频 URL，保留 preview 标记；试听预算最多30秒，不沿用曲库的整曲时长。
- `tools/music_assistant_player/provider.py`：试听也返回可用租约，沿用现有过期释放与设备进度回执机制。
- `src/assistant_app/integrations/music_assistant.py`：允许带真实 URL、租约、有效时长的试听源，继续校验音频源站、固定队列和格式。缺 URL 或只有元数据仍然不能播放。
- `src/assistant_app/application/internet_music.py`：语音预检传递试听标记；实际交接使用试听时长，设备标题显示“（试听）”；不把试听标为整曲。
- `llm_providers.py`：收到 preview 的 scheduled 回执时简短说明“准备播放《歌名》的试听”，不再询问是否试听。记录了本次人工决策。
