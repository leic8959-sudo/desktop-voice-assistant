开源桌面语音助手 · 跑在你自己的电脑上

先在本地启动，再和伊迪斯说话。

这个页面只演示操作顺序。它不连接任何人的网关，不保存密钥，也不能代替你电脑上的安装。

  1. 1. 克隆仓库。 git clone https://github.com/leic8959-sudo/desktop-voice-assistant.git
  2. 2. 准备 Python 3.12，并自己安装依赖。 pip install -r requirements.txt
  3. 3. 生成本地配置。 python tools/init_config.py --lan-ip 127.0.0.1，再把你自己的模型密钥写入 config.local.json。
  4. 4. 启动。 python gateway.py --config config.local.json
  5. 5. 打开本机页面。 http://127.0.0.1:8765。只有这一步发生在你的电脑上。
