## 下单前必须确认的 3 件事

1. **球径**:100mm 起步即可;若要画面更饱满等定制镀膜时上 120mm;
2. **参照物对齐**:"小幻"实物图/链接(确认画面占球面比例、底仓直径比例、膜面是否全罩);
3. **先买阶段一**,花 ¥100 左右验证观感,再决定整机路线甲/乙——重影和亮度不达标,整机投入就要换光学路线,先验证可避免浪费。

## 已知风险(重申)

- GC9A01 IPS 反射后偏暗,AMOLED(RM67162)更亮但要自定义小智板型——两条路线都能走,先 GC9A01 走通再升级;
- 贴膜方案重影明显,最终观感取决于定制镀膜;
- 环境光强时膜面照镜子,底仓内壁必须全黑植绒;
- 圆屏固件布局需要源码级小改(方形→圆形),属于 P09 类固件工作量。
