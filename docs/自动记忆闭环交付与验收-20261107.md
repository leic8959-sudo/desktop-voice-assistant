# 自动记忆闭环交付与验收

日期：2026-11-07。范围：本地源码修复和隔离离线验收。没有重启服务、部署、刷固件、调用真实付费模型、访问外部账号或写真实业务数据库。

## 问题与修复

原有 `AutoMemory.submit` 在入队前按整句的问题、临时词和第一人称规则过滤。因此“我希望以后回答简洁一点，可以吗？”、“以后回答简洁一点”可能没有进入提取队列。不能据此断定所有历史未更新都只有这一原因。

另有两处可见问题：提取结束统一显示 completed / 保存 0 条，无法区分无候选、提取失败、手动保护、删除保护及内容相同；网关按整会话文本哈希去重，A→B→A 的最后 A 会被跳过。

本轮保留“只自动记偏好和长期事项；个人事实手动保存”的人工决策及原注释，调整如下：

- 真实用户文本通过既有语音唤醒、回声和来源许可后进入有界队列。入队硬边界保留关闭、长度、敏感资料和明确不记/忘记；不再按整轮问号或缺少“我”直接丢弃。
- 候选仍须类别、置信度、逐字连续 evidence 和逐字 value 校验；证据必须来自本轮。礼貌请求与真实信息问题分开处理。临时限制不能通过截掉前后文绕过。
- 无第一人称只接受明确面向助手的长期交互偏好；第三方叙述、姓名/职业等个人事实、引用/假设、非自包含指代均保持保守拒绝。否定偏好的 value 必须保留否定原文。
- 沿用既有自动主题更新、手动记录优先、删除主题/内容指纹抑制、TTL、SQLite 事务与索引。没有新增表、迁移或模型执行器；既有初始化逻辑未扩展。
- 网关按实际输入轮次和文本哈希去重：同输入重复转写不重复入队，新输入可以恢复之前的偏好；来源标识保留会话、轮次和哈希。

## 有界跨轮上下文与隐私

最多保留 16 个实际网关会话，每会话最多 4 条真实用户发言；模型提取本轮时最多看到其中 3 条先前发言，绝不把未来轮或其他会话加入。没有会话 ID 的直接调用不复用历史。

历史只帮助理解，不是保存证据；“继续那个项目”等没有本轮自包含证据的指代暂不自动保存。不会用助手回复、网页、工具输出补证据，也不会从历史日志自动回填。

引用窗口为 120 秒；模型请求构造前再次过滤过期历史。worker 闲置每秒清理历史；模型正在提取时清理可能延后至单次 35 秒超时之后。排队发言取出后超过 120 秒会丢弃。队列最多 32 条，原文驻留有界，但不是精确到第 120 秒立即释放所有 Python 对象的承诺。

关闭/设置修改、手动修改、明确不记/忘记和敏感发言都会使旧提取 epoch 作废并清空队列、上下文及候选；关闭服务也清空。已经发送给模型的请求无法撤回，但其旧 epoch 结果不能在之后保存。已提交事务不会因稍后隐私切换而伪报为未发生。

“不要记/忘记”在自动入口仅表示本轮不自动写、切断旧上下文；真实删除已有记录仍走原有经授权的记忆工具或面板忘记入口，不根据关键词直接删库。

## 状态与面板

`/api/memory/settings` 的 `last_extraction` 不含原始对话、模型回复或异常 message，包含实际 observation_id、状态、saved 数、固定原因以及 outcomes 计数。现有记忆面板刷新时展示中文原因，保留纠正/忘记入口，不新增轮询。

| 状态 | 意义 |
| --- | --- |
| queued / processing | 已入队 / 正在处理 |
| filtered | 关闭、敏感、明确不记、来源/长度不符或排队过期；看 reason |
| no_candidate | 有效模型响应为空，或关闭模型后没有字面候选 |
| model_failed | 请求超时、异常、JSON 或根结构无效 |
| candidate_rejected | 类别、证据、来源、稳定性或隐私合同不通过 |
| mode_excluded / review_required | 模式排除 / 等待人工确认 |
| saved / unchanged | 事务已新增或更新 / 内容相同，仅延长到期 |
| manual_protected / deleted_protected | 手动记录优先 / 保持删除抑制 |
| storage_failed / partial_saved | 写入失败 / 部分已提交，部分写入失败 |
| queue_full / failed | 队列已满 / 未完成的处理异常 |

saved 是实际新增/更新条数，unchanged 不计入。保存后上下文刷新失败仍报告 saved，并附 `context_refresh=failed`；不能把已落库结果改成保存 0。多候选部分失败保留 outcomes，页面明确“部分已保存，其余写入失败”。

面板显示的是**最近观察到的一轮**，之后普通寒暄会覆盖之前 saved 摘要；持久化列表仍是实际结果。没有新增无限事件表。异常日志保留调用栈位置与异常类型，同时隐藏异常详情，避免上游异常携带原文、响应或密钥。

## 成本及剩余限制

放开入队粗筛后，普通聊天和问句在没有字面候选时也可能调用既有 `complete_text`，因此模型调用次数和费用可能增加，不能声称成本不变或免费。复用原有 `extract_with_model` 开关，关闭后只执行字面候选。单次提取外层超时 35 秒，队列 32，排队过期 120 秒；没有增加另一套词表门槛、限流器、批处理或依赖。

当前假设、引用和引号仍有整轮保守拒绝；一个有效偏好与这些内容混在同轮可能仍不保存。独立临时分句与稳定偏好可分离，但不是所有自然语言形式都已穷尽。个人事实和归属由提示合同加有限确定性校验保护，模拟错误输出反例通过不等于已证明所有真实模型输出都正确。

真实模型质量/费用、运行服务加载、真实麦克风识别、设备唤醒/声学和真实用户持久化仍待现场验收。没有把临时库成功写入说成真实数据库已经更新。

## 实际验证

工作目录 `I:\new find\desktop_voice_assistant`，Python 3.12，使用既有已安装依赖。

1. `python -m unittest tests.test_auto_memory -q`：首轮 24 项通过，6.694 秒（之后又补充用例）。
2. `python -m unittest tests.test_auto_memory tests.test_input_observation tests.test_chat_wake_order tests.test_gateway_v1 tests.test_assistant_core -q`：首次 72 项中 1 项新增断言失败。测试夹具在浏览器文本后回送另一句固定问候，最近状态被其覆盖。修正为回送同一输入以验证去重，不改产品代码掩盖状态语义。
3. 相同组合命令再次执行：**72 项通过，29.959 秒，OK**；自动记忆模块现为 28 项。隔离网关 TestServer 只绑定临时本机端口，网络守卫检查无非本机连接；全部数据库来自 TemporaryDirectory。

覆盖：礼貌请求、无第一人称、临时/长期混合、问题/假设/引用/个人事实误标/第三方归属/指代错误输出、否定保留、更新/重开回读、手动与删除保护、模式、队列/过期/容量、JSON/上游/存储/刷新失败、有界会话隔离、闲置清理、隐私切断、VoiceSession A→B→A 与同输入去重、真实 HTTP/WebSocket 到 worker/库/API、既有输入和唤醒回归。

测试输出中包含有意构造的无效模拟 JSON 脱敏调用栈、既有非法提醒确认拒绝日志及 aiohttp timeout 参数弃用告警；最终组合无失败。没有执行构建、部署、固件或长期服务启动。没有做浏览器视觉验收。
