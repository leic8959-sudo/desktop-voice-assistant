电脑与媒体

声音来自服务所在电脑。PC快捷控制点击或明确语音指令后直接执行，无需二次确认；媒体上传和账户操作仍走原预览流程。离开页面不会停止播放。

Windows 快捷控制

仅允许以下应用与媒体键。系统媒体键可能控制其他播放器，实际播放和音量需要在电脑核对。

本地白噪音 / 音乐 / 播客

雨声和白噪音由本机合成；音乐和播客由你自备并明确上传，不抓取第三方曲库。噪音按计时循环，音乐和播客播放一次，结束或计时到期即停止。队列最多8项，名称、分类、队列和实际位置保存在本机；重启后保持暂停。对话和主动播报优先暂停，明确继续时从保存位置恢复；异常退出通常回退约5秒，磁盘或调度延迟可能更久。

尚未读取

    原始文件每项最多10MiB、最长30分钟、1～2声道、8～48kHz；WAV需16bit PCM。解码输出最多90MiB，共32项、转换后总容量200MiB，单次转换超45秒会终止。确认绑定原始文件SHA256，上传不自动播放；缺少PyAV时压缩格式不可用。

    日历 OAuth 续期

    需要从提供商完成真实授权取得 Refresh Token。此处提供安全配置和真实刷新请求，不创建授权、不伪装账号已连接。仅本机直连或 HTTPS 可提交秘密，Windows DPAPI 保存；空白保留原值。
