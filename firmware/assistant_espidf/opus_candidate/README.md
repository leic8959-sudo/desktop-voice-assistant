# 原生Opus组件候选

本目录不是正式板型入口，根固件没有将它注册为组件；现有PCM板不会据此切换传输。牛牛已接受Opus，但完整终端接入、目标构建和实机验收仍未完成。具体协议、服务端源码及剩余步骤见项目`docs/native_opus_source_20261113.md`。

组件依赖固定`espressif/esp_audio_codec=2.5.0`，尚未安装。可用`tools/prepare_opus_component_build.py`在仓库外准备C3／C6／S3独立组件工程，只复制源码，不解析或下载依赖。安装与构建由牛牛在相应ESP-IDF环境中执行。

- CaptureEncoder：16kHz单声道20ms／24kbps CBR、无DTX／FEC；编码回调必须同步复制包，错误结束该候选，不静默丢帧。
- PlaybackDecoder：24kHz单声道20ms；由唯一播放任务解码压缩队列中的包，按有效样本裁剪。现有播放PCM与软件AEC参考仍须在真正写入时使用同一份数据。
- SegmentCache：保存从RESET开始到END的独立完整段，冻结后按代次重放尾部。起点前的必要压缩包仍送解码器预热，但标记为0个有效样本，不计入wake_clip字节。满缓存只允许按保留时长淘汰完整段，不能覆盖正在发送或未关闭的段。
- 接入方需保留4秒前缀、2秒唤醒缓存、8秒边界、0.6秒插话预录及发送／播放队列的原业务语义；本组件没有修改现有PCM存储或宣称整机RAM已足够。

必须先解决：实际ESP编码器lookahead。`Initialize`的延迟参数没有默认值，必须按精确实现核实；现有2.5.0公开封装头文件未提供对应查询API，不允许猜0或照搬PC编码器的延迟。独立编码段应在1秒采集PCM后正常End，关闭前缀当前段再冻结；失败调用Abort并检查CANCEL发送结果。

回调和缓存不是线程安全容器；编码器由采集／编码任务独占，解码器由播放任务独占，冻结／代次切换由接入层串行协调。销毁前须停止并join使用者。禁止在WS回调中执行编解码或把候选的空app_main当成完整固件。
